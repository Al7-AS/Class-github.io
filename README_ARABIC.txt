ClassMind AI 7.2 — حزمة تجهيز بناء Windows EXE
تصميم مهندس علي أشرف
================================================

ما الذي تحتويه هذه الحزمة؟
- ملفات مشروع ClassMind AI الأصلية ضمن src وassets، مع إعداد Electron.
- package.json بإصدارات محددة: Electron 35.7.5 وelectron-builder 26.0.12.
- سكريبتات تثبيت وفحص وبناء وتجهيز مبدئي للعمل دون إنترنت.
- لا تحتوي الحزمة الحالية على Node.js for Windows أو node_modules أو ملفات Electron الثنائية أو ملفات EXE جاهزة.
- لم يتم إنشاء ملف EXE ضمن بيئة التسليم هذه؛ يجب تنفيذ خطوات البناء على Windows.

1) النقل من Android إلى Windows
1. نزّل ملف ZIP على الهاتف.
2. انقله إلى الكمبيوتر عبر USB أو LocalSend أو ذاكرة USB.
3. على Windows، فك الضغط إلى مجلد عادي مثل C:\ClassMind-AI-Windows-Builder.
   تجنب تشغيل البرنامج مباشرة من داخل ZIP.
4. استخدم Windows 10/11 x64. الحزمة مضبوطة حالياً لبناء x64.

2) متطلبات البناء الأولية
- Windows 10 أو Windows 11 بنظام 64-bit.
- Node.js 22 LTS x64 مع npm. الموقع الرسمي: https://nodejs.org/
- اتصال إنترنت في مرحلة التجهيز الأولى.
- مساحة فارغة مناسبة لتنزيل Electron وأدوات البناء؛ يُفضّل توفير عدة جيجابايت.
- لا يلزم تثبيت Visual Studio عادةً لهذا المشروع، لأنه لا يستخدم مكتبات Native معروفة في الاعتماديات الحالية.

3) بناء EXE مع الإنترنت لأول مرة
1. ثبّت Node.js 22 LTS x64.
2. افتح مجلد المشروع بعد فك الضغط.
3. شغّل CHECK_ENVIRONMENT.bat.
4. شغّل INSTALL_DEPENDENCIES.bat، وانتظر حتى ينتهي بنجاح.
5. شغّل PREPARE_OFFLINE.bat. هذا يثبت الاعتماديات ثم يبني النسختين مرة واحدة لتجهيز بعض أدوات البناء والكاش.
6. بعد النجاح، ستجد النتائج داخل dist.

4) بناء البرنامج لاحقاً دون إنترنت
- يجب أن تكون قد أكملت PREPARE_OFFLINE.bat بنجاح على جهاز Windows نفسه، وبنفس حساب Windows.
- احتفظ بالمجلد كاملاً، خصوصاً node_modules، ولا تمسح كاش npm أو electron-builder.
- افصل الإنترنت ثم شغّل BUILD_EXE.bat.
- البناء دون إنترنت ليس مضموناً إذا انتقلت الحزمة إلى جهاز آخر؛ أدوات NSIS وwinCodeSign وبعض الحزم قد تُخزّن في كاش المستخدم خارج مجلد المشروع.
- هذه الحزمة ليست Offline Complete: لم تُضمّن فيها ثنائيات Node.js وElectron أو كاش أدوات البناء. كما أن مجلد node_modules الناتج من Windows يجب تجهيزه على Windows، لا على Android.

5) الملفات الناتجة
بحسب نجاح electron-builder، يُفترض أن يحتوي dist على:
- ClassMind-AI-7.2.0-Portable.exe: نسخة محمولة.
- ClassMind-AI-7.2.0-x64.exe أو اسم قريب: مثبت Windows.
اعتمد على أسماء الملفات الفعلية التي يعرضها dist؛ أسماء الناتج قد تختلف حسب إصدار أداة البناء.

6) بيانات البرنامج
يستخدم التطبيق Electron ويخزّن ملف البيانات المشفّر في مجلد userData الخاص بالتطبيق على Windows، وليس داخل مجلد التثبيت، حتى لا تُمحى البيانات عادةً عند تحديث البرنامج.
المسار الدقيق يمكن أن يختلف حسب اسم التطبيق وإصدار Windows. احتفظ دائماً بنسخة احتياطية من داخل البرنامج قبل التحديث أو النقل.
لا تحذف مجلد بيانات المستخدم عند إزالة التطبيق إذا كنت تريد الاحتفاظ بالبيانات.

7) استكشاف الأخطاء
- 'node is not recognized': أعد تثبيت Node.js وحدد خيار إضافته إلى PATH، ثم افتح نافذة جديدة.
- فشل تنزيل Electron: تحقق من الاتصال، ثم أعد تشغيل INSTALL_DEPENDENCIES.bat.
- فشل بناء NSIS أو winCodeSign دون إنترنت: شغّل PREPARE_OFFLINE.bat مع الإنترنت حتى ينجح كاملاً.
- إذا ظهر خطأ، احتفظ بنصه كاملاً؛ لا تعتبر وجود مجلد dist وحده دليلاً على نجاح البناء.
- لا تشغّل سكريبتات البناء من داخل ZIP أو من مجلد محمي بصلاحيات محدودة.

8) ملاحظات تقنية
- التقنية: HTML + CSS + JavaScript داخل Electron، مع src/main.js كنقطة دخول رئيسية وsrc/preload.js كجسر آمن.
- واجهة البرنامج عربية RTL.
- لا توجد مكتبات runtime إضافية في dependencies؛ Electron وelectron-builder أدوات تطوير/بناء.
- الإعداد الحالي يستهدف Windows x64. لا ينتج ARM64 إلا بعد تعديل إعدادات المعمارية وتجهيز أدواته.
- لم يتم اختبار تشغيل EXE على Windows في بيئة التسليم الحالية.

الأيقونة: تم تجهيز build/icon.ico من شعار ClassMind AI المرفق واستخدامه لأيقونة Windows.


تحديث الواجهة (23-10-2026): تم استبدال رمز حرف ع بأيقونة ClassMind AI الذهبية الجديدة، وتحديث أيقونة Windows و favicon. كما أضيفت تحسينات استجابة للشاشات الصغيرة والهواتف: قائمة تنقل أفقية قابلة للتمرير، نماذج وأزرار مناسبة للمس، وتنسيق مرن للجداول والنوافذ. هذا تحديث لواجهة المشروع؛ حزمة Electron الحالية ما زالت مخصصة لبناء Windows وليست APK أندرويد.
