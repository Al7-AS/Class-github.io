# ClassMind AI V4.1 — العقل الذكي

## التشغيل على Windows
1. فك ضغط الملف.
2. افتح المجلد في VS Code.
3. افتح Terminal داخل المجلد ونفّذ `npm install`.
4. بعد اكتمال التثبيت نفّذ `npm start`.

## نظام اشتراكات الشهر الجديد
- عند تسجيل حضور الطالب بالرقم التسلسلي، يظهر فورًا اسم الطالب ومجموعته وصفه وحالة اشتراك الشهر: **مدفوع بالكامل / مدفوع جزئيًا / لم يدفع**.
- سعر الاشتراك يُؤخذ تلقائيًا من سعر المجموعة.
- صفحة **التقارير والتحليل** أصبحت Dashboard مالية تفاعلية باختيار أي شهر.
- تعرض:
  - عدد الطلاب الذين دفعوا بالكامل.
  - عدد الطلاب الذين لم يدفعوا.
  - عدد الطلاب الذين دفعوا جزئيًا.
  - إجمالي المبلغ المحصل.
  - إجمالي المبلغ المفروض تحصيله.
  - إجمالي المبلغ المتبقي.
  - نسبة التحصيل.
  - جدول كامل للطلاب غير المدفوعين: الرقم، الاسم، المجموعة، الصف، السعر، المدفوع، المتبقي، الحالة، وتسجيل دفع.
  - جدول كامل للطلاب المدفوعين.
  - تقرير حسب كل مجموعة.
- لا تحتاج لإضافة سجل "غير مدفوع" لكل طالب؛ النظام يحسب الاستحقاق تلقائيًا من الطلاب والمجموعات والمدفوعات المسجلة.
- المدفوع الجزئي يحسب ضمن المحصل ويظل ضمن الطلاب الذين لم يكتمل سدادهم.

## الإصدار 6.4 — الحضور بالـ QR دون إنترنت أو مكتبات إضافية

- يُنشأ QR رقمي محليًا داخل التطبيق لكل طالب باستخدام JavaScript وSVG؛ لا توجد خدمة ويب أو مكتبة خارجية لتوليد الكود.
- من صفحة الطلاب اضغط «🎫 بطاقة QR» لطباعة بطاقة الطالب، أو من صفحة الحضور اختر «طباعة بطاقات الطلاب» لطباعة بطاقات كل الطلاب النشطين.
- **قارئ USB:** وصّله بالكمبيوتر (يعمل عادةً كلوحة مفاتيح)، اضغط داخل خانة الرقم، ثم امسح QR؛ سيكتب القارئ الرقم ويمكن الضغط Enter للتسجيل.
- **كاميرا اللابتوب:** افتح صفحة الحضور واضغط «تشغيل كاميرا اللابتوب»، واسمح للتطبيق باستخدام الكاميرا، ثم وجّهها إلى QR. تعتمد قراءة الكاميرا على دعم `BarcodeDetector` المدمج في Chromium؛ إن لم يكن مدعومًا في نسخة Electron الحالية فسيظهر تنبيه، ويمكن استخدام قارئ USB دون أي تثبيت إضافي.
- يعمل حفظ الحضور وقراءة القارئ USB محليًا دون اتصال بالإنترنت. يتم منع إضافة سجل حضور مكرر للطالب في التاريخ نفسه عند المسح بالكاميرا.
- لا يلزم تثبيت أي مكتبات JavaScript إضافية. متطلب تشغيل المشروع كما هو سابقًا: تثبيت حزمة Electron الخاصة بالمشروع مرة واحدة عند إعداد بيئة التطوير.
